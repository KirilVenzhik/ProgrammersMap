## P1 — Публичный чеклист

### P1-01 Ревизия slug'ов — `done`
Opus проверяет slug'и в topics.json: короткие, читаемые, латиница, без транслит-мусора (`join`, `sql-injections` лучше длинного транслита). Правит одним коммитом.
Приёмка: тесты P0-02 зелёные, slug'и ≤ 40 символов.

### P1-02 Layout и стили — `done`
`_Layout.cshtml`, `wwwroot/css/site.css` по прототипу (палитра, шрифты, тёмная тема, адаптив).
Приёмка: визуально соответствует прототипу; нет внешних ресурсов кроме Google Fonts.

### P1-03 Главная = чеклист — `done`
Перенести прототип: карта-сетка прогресса, разделы, группы, темы с уровнями, сайдбар с прогрессом по разделам. Каждая тема — ссылка на свою страницу + чекбокс.
Приёмка: все 254 темы на странице; HTML рендерится сервером (без JS темы видны).

### P1-04 Прогресс на клиенте — `done`
`wwwroot/js/progress.js`: localStorage по ARCHITECTURE.md, фильтры (поиск, уровень, скрыть изученное), сброс с подтверждением. Работает и на главной, и на страницах раздела/темы.
Приёмка: ручной чеклист в описании коммита; JS без ошибок в консоли.

### P1-05 Страница раздела — `done`
`/{sectionSlug}`: заголовок, группы, темы, прогресс раздела. 404 для неизвестного.
