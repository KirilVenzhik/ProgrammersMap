# Бриф

## Продукт
«Карта программиста» — русскоязычный подробный чеклист тем программирования (~250 тем, 14 разделов, уровни Junior/Middle/Senior).
Пользователь отмечает изученное и видит прогресс. Позже у каждой темы появится контент (уроки, тесты).

## Аудитория
Начинающие и junior-разработчики, которые учатся сами и хотят понимать «что ещё не знаю». Русскоязычные.

## Отличие от roadmap.sh
Русский язык; каждая тема — отдельная SEO-страница; позже проверка знаний тестами, а не просто галочка.

## Монетизация (по очереди)
1. SEO-трафик: страница на каждую тему (без денег, фундамент).
2. Партнёрские ссылки «Где изучить» на странице темы.
3. Freemium-подписка Pro: синхронизация прогресса, тесты по темам, интервальное повторение.
4. Платные треки (разовая покупка), например «.NET Backend Junior».
5. B2B: доступ работодателей к кандидатам, white-label для онбординга.
Рекламные сети не используем.

## Вторая цель
Проект — портфолио автора для поиска работы Junior .NET Backend. Поэтому качество кода, тесты и README важны наравне с фичами.
