# Роадмап

Текущая фаза: **P0**

Переход на следующую фазу — только после проверки человеком. Opus в конце фазы пишет итог в STATUS.md и останавливается.

| Фаза | Цель | Готово, когда |
|---|---|---|
| P0 Каркас | Решение, проекты, CI, базовая страница | `dotnet build`/`test` зелёные локально и в GitHub Actions |
| P1 Публичный чеклист | Перенос прототипа на Razor Pages + страницы тем + SEO | Все 254 темы доступны по URL, прогресс работает, sitemap валиден |
| P2 Каркас контента | Шаблон страницы темы: «Где изучить», место под урок | У темы может быть markdown-файл контента и список ресурсов |
| P3 Аккаунты | Identity, PostgreSQL, синхронизация прогресса | Вход, прогресс на сервере, слияние с localStorage |
| P4 Монетизация | Pro-подписка, тесты по темам, треки | Требует решений человека (платёжка, цены) — планировать вместе |
| P5 Деплой | Хостинг, домен, мониторинг | `needs-human` |

Задачи фаз P0–P1 расписаны в BACKLOG.md. Фазы P2+ Opus детализирует командой `/plan-phase`, когда до них дойдёт.
