# Карта контекста

Читай этот файл первым в каждом новом чате. Он говорит, где лежит информация, а не саму информацию.
Правило: открывай файл только когда он нужен для текущего вопроса.

| Вопрос | Где смотреть | Кто обновляет |
|---|---|---|
| Что за проект, для кого, как зарабатываем | `docs/BRIEF.md` | человек / Opus с согласия |
| Что происходит прямо сейчас, что было в прошлой сессии | `docs/STATUS.md` | Opus, в конце каждой задачи |
| Фазы проекта и где мы | `docs/ROADMAP.md` | Opus, человек утверждает переход фазы |
| Конкретные задачи, статусы, критерии приёмки | `docs/BACKLOG.md` | Opus |
| Стек, структура решения, модель данных, URL | `docs/ARCHITECTURE.md` | Opus |
| Почему сделано так, а не иначе | `docs/DECISIONS.md` | Opus, до реализации решения |
| Стиль кода, тесты, коммиты | `docs/CONVENTIONS.md` | Opus |
| Список тем курса (источник правды) | `content/topics.json` | Opus / implementer по задаче |
| Как выглядит UI (визуальный эталон) | `prototype/index.html` | не трогать, только читать |
| Правила для агентов | `CLAUDE.md`, `.claude/agents/*.md` | человек |
| Рабочий цикл | `.claude/commands/next.md` | человек |
| Как запускать (для человека) | `SETUP.md` | человек |

## Типовые маршруты
- Начинаю работу → `STATUS.md` → `BACKLOG.md` (первая `todo` задача текущей фазы).
- Пишу код → задача из `BACKLOG.md` + `ARCHITECTURE.md` + `CONVENTIONS.md`.
- Делаю UI → `prototype/index.html` (цвета, шрифты, поведение) + `ARCHITECTURE.md` раздел «Frontend».
- Сомневаюсь в подходе → `DECISIONS.md`; нет ответа → новая запись ADR.
- Вопрос про деньги/продукт → `BRIEF.md`.

## Правила ведения
- STATUS.md короткий: текущее состояние + последние 5 записей лога. Старое сворачивать в одну строку.
- Новый документ? Добавь строку в эту таблицу, иначе его никто не найдёт.
